# Customer Shopping Behavior Analysis

## Overview
This project analyzes customer shopping behavior to identify purchasing patterns, product preferences, and useful business insights from customer shopping data.

## Objectives
- Explore and understand the customer shopping dataset.
- Clean and analyze data using Python and Pandas.
- Answer business questions using SQL.
- Visualize important findings with Matplotlib.
- Present key insights in a dashboard to support data-driven decisions.

## Tools & Technologies
- **Python** — analysis and data processing
- **Pandas** — data cleaning and exploratory data analysis
- **SQL** — business questions and querying
- **Matplotlib** — data visualization
- **CSV** — source dataset
- **Dashboard** — summary of key metrics and findings

## Project Workflow
1. Load the original CSV dataset.
2. Inspect the data and perform cleaning where required.
3. Conduct exploratory data analysis with Pandas.
4. Use SQL queries to answer business-related questions.
5. Create charts to communicate relevant trends.
6. Present the results in a dashboard and summarize actionable insights.

## Repository Contents
- `customer_shopping_behavior.csv` — source dataset
- `*.py` — Python analysis and visualization code
- `*.sql` — SQL queries used to solve business questions
- `dashboard.*` — dashboard files
